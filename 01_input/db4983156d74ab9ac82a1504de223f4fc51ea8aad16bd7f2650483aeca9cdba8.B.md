```text
Compatible Difference
=
같은 넓은 Process 안에 공존할 수 있는 비동일 상태

Conflict
=
서로 양립시키려면 Version·Authority·Mechanism·Identity 해결근거가 필요한 상태

Ambiguity
=
표현이 여러 객체·시계·권위·상태를 가리킬 수 있어 추가 Type Binding이 필요한 상태

Counterexample
=
단순화된 일반경로가 항상 성립하지 않음을 보여 주는 예외사건

Exclusion
=
현재 Source-backed Result로 승격하면 안 되는 객체·주장·분류

Missing Counterpart
=
필요하지만 현재 Exact Source Object가 결속되지 않은 대상

Unresolved
=
판정에 필요한 근거·버전·데이터·정책이 아직 닫히지 않은 상태

Required Next Data
=
Unresolved를 해소하기 위해 다음 Cycle에서 요구하는 구체 입력
```

Difference
≠ Conflict

Ambiguity
≠ Missing Counterpart

Counterexample
≠ Current Default

Exclusion
≠ Deletion

Unresolved
≠ Failure

Next Data
